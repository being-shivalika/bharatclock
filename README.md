Bharat Clock 🕒

A simple React app that displays the current date and time in India (IST) and updates it in real time.

This project is built as a tutorial follow-up to practice:

React components
State management
Time handling in JavaScript
Clean JSX structure

Features

Shows current Indian date & time
Auto-updates every second
Minimal and beginner-friendly UI
No external libraries used

Tech Stack

React
JavaScript
CSS
Vite (development server)
